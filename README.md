# Настольная игра "Шахматы"

Консольная реализация классических шахмат на Python.

## Требования

- Python 3.10 или выше

## Установка

Клонируйте репозиторий:
```bash
git clone https://github.com/neronovtf/chess
cd chess
```

## Запуск
- Просто дважды кликните на start.bat (Windows)
- Или через консоль
```bash
python main.py
```
